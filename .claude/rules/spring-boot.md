# Spring Boot rules (in addition to java.md)

## Structure
- Package by feature: `…/orders/{OrderController, OrderService, OrderRepository, Order, OrderDto}`. Shared infrastructure in `…/common/` only once it's used by two or more features.
- **Layers inside a feature:** controller (HTTP mapping and validation only) → service (transactions, domain logic) → repository. Controllers never touch repositories directly. Entities never leave the service layer: map them to `record` DTOs.

## Dependency injection and config
- **Constructor injection only**, with `final` fields. No `@Autowired` on fields or setters. A single constructor needs no annotation.
- Typed config: `@ConfigurationProperties` records with `@Validated`. No `@Value` sprinkled through code.
- Dependencies: Spring Boot manages library versions. Add the alias to `gradle/libs.versions.toml` without a version, and give one only for libraries Boot doesn't manage.
- Profiles: `application.yml` (defaults), `application-local.yml`, `application-test.yml`. Secrets come from env vars only (`${DB_PASSWORD}`).

## Web
- Validate request DTOs with Jakarta Bean Validation (`@Valid`, `@NotBlank`, …).
- Errors: one `@RestControllerAdvice` mapping domain exceptions to **`ProblemDetail`** (RFC 9457). Never leak stack traces. Enable `spring.mvc.problemdetails.enabled=true`.
- Return explicit status codes (`ResponseEntity.created(uri)` for POST). Version public APIs (`/api/v1/...`).
- API contract (OpenAPI) is generated by springdoc and checked against design.md.

## Persistence
- **Flyway** migrations in `src/main/resources/db/migration`, `V<N>__description.sql`. Never edit a migration that has run anywhere; add a new one. `spring.jpa.hibernate.ddl-auto=validate`.
- `@Transactional` on service methods, not on controllers or repositories. Read-only methods: `@Transactional(readOnly = true)`.
- Watch for N+1 queries: use fetch joins or entity graphs, and assert query counts in integration tests for list endpoints.
- Disable open-in-view: `spring.jpa.open-in-view=false`.

## Observability and ops
- Actuator with `health`, `info`, `metrics`, `prometheus` exposed. Everything else stays off in prod.
- Structured logging (`logging.structured.format.console=ecs`). Add a correlation ID per request.
- Graceful shutdown is on (`server.shutdown=graceful`).

## Tests
- **Slice tests first:** `@WebMvcTest` for controllers (with `@MockitoBean` for the service), `@DataJpaTest` for repositories.
- `@SpringBootTest` only for a few end-to-end flows, as `*IT` in `src/integrationTest/java` (the `integrationTest` Gradle suite).
- Real database in integration tests via **Testcontainers** with `@ServiceConnection`. No H2 standing in for Postgres.
- Don't create a new Spring context per test class by accident (vary `@MockitoBean` sets as little as possible).
